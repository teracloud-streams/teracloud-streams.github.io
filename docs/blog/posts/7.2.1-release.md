# Teracloud Streams 7.2.1 is Now Available

We're excited to announce the release of **Teracloud Streams 7.2.1**, bringing enhanced platform support, powerful new capabilities, and improved reliability for real-time data processing.

Streams 7.2.1 now fully supports Red Hat Enterprise Linux (RHEL) 10.0 or later, WebSocket support for the Data Exchange service, and a new web service backend. You can checkout the release highlights on the [release page](https://streams.teracloud.com/releases/7.2.1) or the full set of release notes in the [product documentation](https://doc.streams.teracloud.com/com.ibm.streams.welcome.doc/doc/streams_rel_notes_overview.html).

If you want to try it out, we've updated our Quick Start Edition (QSE) on [Docker Hub](https://hub.docker.com/r/teracloudaps/streams-qse). You can follow [these steps](/gettingstarted/basics/#set-up-a-development-environment) to set up a 7.2.1 development environment.

Lastly, feel free to [contact us](https://streams-website.teracloud.com/contact) if you have questions about the new release or are interested in a full product installer.
